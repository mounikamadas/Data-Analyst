# Tools & Technologies

This document provides an overview of the tools and technologies I use in my day-to-day work as part of enterprise data platform operations.

---

# Snowflake

Snowflake is a cloud-native data warehouse that enables organizations to store, process, and analyze large volumes of data. It separates compute and storage, making it scalable, secure, and cost-effective.

## Why is Snowflake Used?

- Cloud-based data warehouse
- High-performance SQL analytics
- Independent compute and storage scaling
- Secure data sharing
- Supports structured and semi-structured data

## How I Use Snowflake

- Execute SQL queries to validate backend data.
- Analyze tables, views, and schemas during investigations.
- Verify data after approved changes are implemented.
- Support backend analysis and issue investigation.

---

# AutoSys

AutoSys is an enterprise workload automation and job scheduling tool used to schedule, monitor, and manage batch jobs and ETL workflows.

## Why is AutoSys Used?

- Automates scheduled jobs
- Manages job dependencies
- Monitors workflow execution
- Generates job status and alerts

## How I Use AutoSys

- Monitor scheduled ETL jobs.
- Investigate failed or delayed jobs.
- Analyze job execution details.
- Validate completion of dependent workflows.
- Perform initial troubleshooting and recovery activities when required.

---

# PuTTY

## What is PuTTY?

PuTTY is an SSH client used to securely access remote Linux servers.

## Why is PuTTY Used?

- Secure remote server access
- Log analysis
- Shell script verification
- File validation
- Operational suppor

## How I Use PuTTY

- Access Linux servers securely.
- Review application and error logs.
- Analyze shell scripts during investigations.
- Verify file availability.
- Investigate execution failures.

---

# Amazon S3

Amazon Simple Storage Service (Amazon S3) is a cloud object storage service used to securely store and retrieve files.

## Why is Amazon S3 Used?

- Store source data files
- Highly durable storage
- Secure file management
- Scalable object storage

## How I Use Amazon S3

- Verify availability of source files required for ETL jobs.
- Investigate missing or delayed source files during issue analysis.
- Validate source files as part of backend troubleshooting.

# ETL

ETL (Extract, Transform, Load) is the process of extracting data from source systems, transforming it into the required format, and loading it into a target system.

## How I Use ETL

- Trace data lineage across ETL layers.
- Investigate backend data flow.
- Validate data movement.
- Support root cause analysis.

## Why is ServiceNow Used?

- Incident Management
- Service Requests
- Change Requests
- Task Management
- Workflow Tracking

## How I Use ServiceNow

- Work on assigned incidents and operational tasks.

- Document investigation findings and resolution details.
